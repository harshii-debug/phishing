# 🛡️ PhishGuard — Phishing Email Detection System

A modern cybersecurity web application that analyzes email content and identifies potential phishing threats using email text, URLs, suspicious keywords, and other phishing indicators.

## 📌 Project Overview

Phishing attacks are one of the most common cybersecurity threats. Attackers often use fake emails to trick users into revealing passwords, OTPs, banking information, or clicking malicious links.

**PhishGuard** provides a simple interface where users can paste an email and analyze it for potential phishing indicators.

The system examines the email and generates:

- 🔴 Phishing / 🟢 Safe classification
- 📊 Risk score
- ⚠️ Suspicious keywords
- 🔗 URL analysis
- 🔐 Credential-request detection
- 🚨 Urgent-language detection
- 📈 Email feature statistics

> **Note:** The current web version uses frontend rule-based analysis for demonstration purposes. It does not claim to run a real Scikit-learn model in the browser.

---

## ✨ Features

### 📧 Email Analysis
Users can enter:

- Email subject
- Complete email content

The application analyzes the provided information and generates a security assessment.

### 🔍 Phishing Indicators

The system checks for:

- Suspicious keywords
- Urgent language
- Password requests
- OTP requests
- Login requests
- Account verification requests
- Suspicious URLs
- HTTP links
- Excessive punctuation
- Excessive capital letters
- Special characters
- Digits

### 📊 Risk Scoring

The email receives a risk score from **0–100**.

| Risk Score | Classification | Risk Level |
|------------|----------------|------------|
| 0–29 | Safe | Low |
| 30–59 | Suspicious | Medium |
| 60–100 | Phishing | High |

### 📈 Email Feature Analysis

The application displays:

- Email length
- Number of URLs
- Suspicious keyword count
- Special character count
- Digit count
- Exclamation mark count
- HTTPS URL count
- HTTP URL count

### 🧠 Model Performance Dashboard

The interface also includes a model-performance section with sample metrics:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

These metrics are clearly presented as **sample model metrics** and are not falsely represented as being generated by the frontend demo.
